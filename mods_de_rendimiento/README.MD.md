# Guía de Instalación de Mods

Este repositorio contiene los mods necesarios para el cliente. Todos los archivos con extensión `.jar` ubicados en este directorio deben agregarse a tu instalación de Minecraft.

---

## Pasos para la instalación

1. **Descargar los mods:**
   * Descargá todos los archivos `.jar` presentes en la carpeta de este repositorio.

2. **Abrir la carpeta de mods de Minecraft:**
   * **Windows:** Presioná las teclas `Win + R`, escribí `%appdata%\.minecraft` y presioná *Enter*.
   * **Linux:** Abrí la ruta `~/.minecraft`.
   * **macOS:** Abrí `~/Library/Application Support/minecraft`.

3. **Copiar los archivos:**
   * Entrá a la carpeta `mods` (si no existe, creala con ese nombre en minúsculas).
   * Copiá o pegá todos los archivos `.jar` descargados dentro de la carpeta `mods`.

4. **Iniciar el juego:**
   * Abrí tu launcher de Minecraft, seleccioná el perfil correspondiente al modloader (Fabric, Forge o NeoForge según la versión) e iniciá el juego.
